# Jarvis Server

A server implementation for the Jarvis project.

## Description

This project provides server-side functionality for Jarvis.

## Installation

```bash
# Clone the repository
git clone https://github.com/NadavZ-sketch/Jarvis-server-nadav.git

# Navigate to the project directory
cd Jarvis-server-nadav

# Install dependencies
npm install
```

## Usage

```bash
# Start the server
npm start
```

## Optional web search via MCP

Enable [Parallel Search MCP](docs/parallel-search-mcp.md) for keyless web search
and page fetching through Jarvis's MCP client API.
